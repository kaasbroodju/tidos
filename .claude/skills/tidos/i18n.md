# Internationalization (`i18n` feature flag)

Fluent-based (`.ftl`) translations for Tidos, gated behind the `i18n` Cargo
feature. Read this file whenever a task involves translations, locales, or
the `i18n!`/`enable_i18n!` macros.

> **Feature flag required.** Add `"i18n"` to the `features` list in
> `Cargo.toml`. The feature pulls in [Fluent](https://projectfluent.org/) for
> message resolution (pluralization, gender/selector variants, variables).

## 1. `Cargo.toml`

```toml
tidos = { version = "0.8.0-rc.2", features = ["rocket", "i18n"] }
```

## 2. `Tidos.toml` — translation configuration

Create a `Tidos.toml` in the project root:

```toml
[default]
resource_location = "translations"
default_locale = "en-US"
resources = ["common.ftl"]
```

`enable_i18n!()` reads this file (or `TIDOS_I18N_`-prefixed environment
variables) via [Figment](https://docs.rs/figment) at startup.

Place `.ftl` files under `resource_location`, one directory per locale:

```
translations/
├── en-US/
│   └── common.ftl
└── nl-NL/
    └── common.ftl
```

## 3. Initialise in `main.rs`

Call `enable_i18n!()` once, at the top level of `main.rs`, before launching
the server:

```rust
use tidos::i18n::enable_i18n;

enable_i18n!();

#[rocket::main]
async fn main() {
    // launch Rocket here
}
```

## 4. Add `lang: Lang` to route handlers

The locale is expected as the first path segment (e.g. `/en-US` or
`/nl-NL`). `Lang` is a Rocket request guard; `page!` picks it up
automatically whenever `lang: Lang` is a parameter on the handler:

```rust
use tidos::i18n::Lang;
use tidos::{Page, page};

#[get("/<lang>")]
pub fn index(lang: Lang) -> Page {
    page! {
        <main>
            <Greeting />
        </main>
    }
}
```

## 5. Translate strings with `i18n!`

Import and call `i18n!` inside any component with a Fluent message key:

```rust
use tidos::i18n::i18n;

// Simple key lookup:
i18n!("greeting")

// With Fluent variables (each variable is a ("key", value) tuple):
i18n!("shared-photos", ("userName", "Anne"), ("userGender", "female"), ("photoCount", 3))
```

Full component example:

```rust
use tidos::{view, Component, Page};
use tidos::i18n::i18n;

pub struct Greeting;

impl Component for Greeting {
    fn to_render(&self, page: &mut Page) {
        view! {
            <section>
                <h1>{i18n!("greeting")}</h1>
                <p>{i18n!("shared-photos", ("userName", "Anne"), ("userGender", "female"), ("photoCount", 3))}</p>
            </section>
        }
    }
}
```

## Fluent file example

```ftl
greeting = Hello

shared-photos =
    {$userName} {$photoCount ->
        [one] added a new photo
       *[other] added {$photoCount} new photos
    } to {$userGender ->
        [male] his stream
        [female] her stream
       *[other] their stream
    }.
```

Fluent supports pluralization, gender variants, and other selectors out of
the box, resolved server-side at render time based on `page.lang`.
